# 🐍 Fundamentos de Linguagem Python (DSA)

Repositório dedicado ao curso **"Fundamentos de Linguagem Python: Do Básico a Aplicações de IA"** da [Data Science Academy](https://www.datascienceacademy.com.br/).

## 📌 Sobre o Curso
Trilha completa de aprendizado focada em levar o aluno do zero à criação de soluções de Inteligência Artificial, abrangendo Data Science, Machine Learning, Deep Learning e IA Generativa.

**Carga Horária:** 96 horas

## 🛠️ Tecnologias e Bibliotecas
* **Python** (Linguagem base)
* **Análise de Dados:** NumPy, Pandas, Matplotlib, Statsmodels
* **Machine Learning:** Scikit-Learn
* **Deep Learning:** PyTorch
* **IA Generativa & LLMs:** LangChain, RAG, CrewAI
* **Deploy:** Streamlit

## 📂 Projetos e Estudos de Caso

### 📚 Estudos de Caso
1.  **DSA AI Coder:** Assistente de IA para programação Python.
2.  **Game:** Fundamentos de lógica para construção de jogos.
3.  **LLM do Zero:** Guia didático da arquitetura Transformer.

### 🚀 Mini-Projetos
1.  **Análise de Vendas (E-commerce):** Pandas, NumPy e Matplotlib.
2.  **Sistema Bancário (POO):** Aplicação Full-Stack.
3.  **Análise de Marketing:** Estatística com NumPy.
4.  **Engenharia de Atributos:** Limpeza e EDA de vendas.
5.  **Análise de Churn:** Modelagem estatística.
6.  **Análise de Sentimentos:** Classificação de texto.
7.  **Classificação de Imagens:** Deep Learning com PyTorch.
8.  **Assistente Jurídico:** IA Generativa e RAG com LangChain.
9.  **Planejamento de Viagens:** Agentes autônomos com CrewAI.
10. **Dashboard de Vendas:** Data App com Streamlit.
